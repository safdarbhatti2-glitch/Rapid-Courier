# UAE Logistics Platform — Antigravity Development Pack

This specification is for building a production-ready UAE courier/logistics website inspired by the information architecture and user flows of Gulf Express, but with original branding, UI, copy, assets, and implementation.

Reference site reviewed: https://gulfexpress.org/

Target stack:
- PHP 8.2+ compatible
- MySQL 8 / MariaDB-compatible SQL
- HTML5, CSS3, JavaScript
- Bootstrap 5 or a lightweight custom component system
- PDO with prepared statements
- Apache/.htaccess
- Hostinger Business shared hosting
- No Node.js runtime required in production
- Optional Composer dependencies only when they are compatible with shared hosting

Core modules:
1. Public marketing website
2. Shipment booking
3. Real-time-style shipment tracking/status history
4. Customer portal
5. Admin dashboard
6. Invoice creation and management
7. Quotation creation, approval and conversion
8. Customers, addresses, pricing, services and locations
9. Notifications/audit logs
10. Reports and exports

Important:
- Do not copy Gulf Express trademarks, logo, text, images, source code, or exact visual identity.
- Use it only as a UX/reference benchmark.
- All demo data must be clearly fictional.
- Build security, validation, auditability and maintainability into the first version.
