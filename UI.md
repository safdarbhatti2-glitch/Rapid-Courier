# UI Specification

## Brand direction
Create an original UAE logistics brand. Suggested visual direction:
- professional
- fast
- clean
- trustworthy
- premium
- logistics-focused

Do not copy Gulf Express branding.

## Components
- Navbar
- Hero
- CTA
- ServiceCard
- TrackingCard
- StatusBadge
- MetricCard
- DataTable
- FilterBar
- FormField
- Modal
- Toast
- EmptyState
- Pagination
- Timeline
- InvoicePreview
- QuotePreview

## Tracking timeline
Use a vertical timeline on desktop and a compact mobile timeline.

Each event:
time
location
status
public note

## Tables
Desktop:
- sticky header where useful
- sortable columns
- filters
- pagination

Mobile:
- horizontal scrolling only when necessary
- or convert rows into cards for high-density records

## Forms
Every field:
- label
- help text where needed
- server error
- client feedback
- required indicator
- accessible name

## Invoice UI
Use a clean accounting-document layout:
header → billing → shipment reference → line items → totals → payment status → notes → footer.

Provide print CSS.
